# Aura Leather Co.

Aura Leather Co. is a full-stack luxury leather-goods storefront built with Node.js, Express, Prisma, SQLite, React motion micro-islands, GSAP, OGL, and vanilla HTML/CSS/JavaScript pages. The download includes the expanded 25-product catalog, 13 categories, local catalog images, the workshop hero image, FoldText, homepage-only FlexCarousel, SpecularButton enhancement, authentication, cart, checkout, reviews, newsletter, and admin product management.

## Requirements

- Node.js 20 LTS or newer
- npm 10 or newer
- No separate database server is required. Development uses SQLite.

This project is a multi-page Express application, not a React Router SPA. Its actual client dependencies are React, ReactDOM, GSAP, and OGL; React Router is not required because routing is handled by Express page routes and links.

## Quick start with npm

From the project directory:

```sh
npm install
cp .env.example .env
```

For a plain local HTTP run, edit `.env` and set:

```dotenv
AURA_DATABASE_URL="file:./dev.db"
JWT_SECRET="replace-with-a-long-random-secret-before-public-deployment"
PORT=3000
COOKIE_MODE=local-http
```

Then generate the Prisma client, create/sync the SQLite schema, seed the catalog, and build the motion bundle:

```sh
npm run db:generate
npm run db:setup
npm run build
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

`npm run dev` starts the development server with Node's watch mode. For a production-like local start after building, use:

```sh
npm start
```

The application listens on port `3000` unless `PORT` is changed.

## Available scripts

```sh
npm run dev          # Start Express with Node watch mode
npm start            # Start Express without watch mode
npm run build        # Bundle FoldText, FlexCarousel, and SpecularButton motion code
npm run build:motion # Build the motion bundle and component CSS files
npm run db:generate  # Generate the Prisma client
npm run db:push      # Sync prisma/schema.prisma to SQLite
npm run db:seed      # Seed/update categories, products, users, and reviews
npm run db:setup     # Run db:push and db:seed
```

The checked-in `prisma/dev.db` is included as a development snapshot, but `npm run db:setup` is repeatable and recreates the catalog state from `seeds/seedData.js`.

## Storefront routes

- `/` — landing page with FoldText, homepage-only FlexCarousel, and category grid
- `/shop` — catalog grid with category, audience, price, search, and sort filters
- `/product/:id` — standard image-gallery PDP with structured specifications and SpecularButton CTAs
- `/cart` — guest/member shopping bag
- `/checkout` — simulated checkout flow
- `/account` — authentication, profile, orders, and reviews
- `/admin` — development product/category management
- `/about`, `/contact` — informational pages

## Asset and data organization

- `public/assets/hero-leather-workshop.png` — supplied workshop hero crop
- `public/assets/catalog/` — bundled catalog photographs used by products and categories
- `seeds/seedData.js` — 25 products, 13 categories, prices, inventory, local image paths, and structured specifications
- `prisma/schema.prisma` — relational SQLite schema, including the product `specifications` JSON field
- `prisma/seed.js` — repeatable database initialization and development users/reviews
- `src/components/FlexCarousel.jsx` — homepage-only OGL carousel
- `src/components/SpecularButton.jsx` — shared WebGL2/specular enhancement for standard controls
- `src/motion/index.jsx` — FoldText, SpecularButton, and FlexCarousel motion bundle entrypoint
- `public/js/ui-motion.bundle.js` — checked-in browser bundle generated by `npm run build`

All product and category images required by the catalog are included locally in the ZIP, so the storefront does not depend on an external image CDN after download.

## Troubleshooting

If the browser shows a stale database or catalog, run:

```sh
npm run db:setup
npm run build
```

If port 3000 is busy, use another port:

```sh
PORT=3001 npm run dev
```

For public HTTPS deployments, use secure cookies by removing `COOKIE_MODE=local-http` or setting the deployment's secure-cookie mode, and replace the development JWT secret and administrator credentials.
